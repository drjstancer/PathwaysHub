# Source Repository Preservation Policy

The original repositories and systems remain in place and unchanged unless the user explicitly requests an edit to one of them.

These repositories are historical/source systems and should be treated as read-only references during ecosystem consolidation:

- drjstancer/CaPS
- drjstancer/PAWS
- drjstancer/PSMS
- any other pre-existing source repository discovered during consolidation

## Canonical build repository

All new connected-ecosystem development occurs in:

- drjstancer/PathwaysHub

## Why preserve the originals

- preserves design and development history
- protects working prototypes and prior systems
- allows feature provenance and comparison
- supports future migration validation
- avoids destructive consolidation

Features may be studied, adapted, or reimplemented in PathwaysHub, but the source repositories are not migrated, deleted, archived, or rewritten as part of this build.
